- **Game HTML (Html-Games):** Chơi trực tiếp trên web không cần cài đặt:
  - **2048:** Game 2048 phong cách đáng yêu.
  - **Neon Runner 3D:** Game chạy vô tận đồ họa 3D.
  - **Octopus Flappy:** Game Flappy phong cách bạch tuộc vũ trụ.
  - **Snake:** Game Snake phong cách arcade.

- **Markdown Live:** Trình soạn thảo Markdown thời gian thực:
  - Soạn thảo & Xem trước tức thì.
  - Đồng bộ cuộn trang.
  - Hộp thông báo đặc biệt (GFM Alerts / Callouts): Hỗ trợ chuẩn ghi chú của GitHub với biểu tượng Lucide Icons và màu sắc phân loại.
  - Công thức toán học (KaTeX / LaTeX).
  - Vẽ biểu đồ tự động (Mermaid.js).
  - Tô màu mã nguồn (Syntax Highlighting).
  - Xuất PDF & Sao chép nhanh.

- **Công cụ (Tools):**

  - Python Script downscale video 4K/1080p → 720p hàng loạt.
